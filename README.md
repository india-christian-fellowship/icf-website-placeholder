# ICF website (placeholder)

Static placeholder for India Christian Fellowship, Toronto, until the Next.js + Payload site is ready.
Content comes from the archived WordPress pages (Feb–Mar 2026). No build step: plain HTML and one stylesheet.

Page paths match the old WordPress URLs (`/about-us/`, `/our-events-and-meetings/`, `/video-gallery/`, `/contact/`), so existing links keep working. `/our-gallery/` redirects to the video gallery.

Preview locally:

    python3 -m http.server 8000
